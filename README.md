# Robot Vision XR — V24 Zero Install

## Objetivo
Demo 100% browser-only:
abrir URL → permitir cámara → usarla.

## No requiere
- WebXR
- ARCore
- Google Play Services for AR
- APK
- instalación de software
- modelos de IA

## Modos
- RGB
- VISUAL DEPTH
- POINT CLOUD
- POINT+SHAPES

- NEAR
- MID
- FAR
