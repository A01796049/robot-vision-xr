- Persistencia corta de 3 frames para que la nube se vea más continua.
- WORLD 3D con modo `WORLD CAM` y `WORLD TOP`.
- Controles de densidad (`LOW/MED/HIGH`) y rango (`2.5M/4.0M/6.5M`).
